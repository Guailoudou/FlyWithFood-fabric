## 饥饿飞行 Mod 实现计划

### 1. 重构包名和Mod ID
- 将包名从 `com.example` 改为 `com.gldhn.flywithfood`
- 更新 `fabric.mod.json` 中的 mod id 为 `flywithfood`
- 更新 mixins 配置文件

### 2. 创建配置系统
- 创建 `FlyConfig` 类，使用 Fabric API 的配置系统
- 配置项包括：
  - `hungerDrainPerSecond`: 每秒扣除的饥饿值（默认 1.0）
  - `minHungerToFly`: 允许飞行的最低饥饿值（默认 6，即3个鸡腿）

### 3. 创建玩家飞行状态管理
- 创建 `FlyStateData` 类，使用 `TrackedData` 存储玩家的飞行开关状态
- 创建 `IFlyState` 接口和 Mixin 扩展 `PlayerEntity`

### 4. 注册 `/fly` 指令
- 创建 `FlyCommand` 类
- 实现 `/fly on` 和 `/fly off` 子命令
- 仅允许玩家执行，并给予相应反馈

### 5. 实现飞行逻辑
- 使用 `ServerTickEvents.END_SERVER_TICK` 监听服务器 tick
- 检测飞行中的玩家，按配置扣除饥饿值
- 当饥饿值低于阈值时自动关闭飞行并提示玩家

### 6. 清理模板文件
- 删除无用的 `ExampleMixin.java` 和 `ExampleClientMixin.java`
- 更新 `ExampleModClient.java`
